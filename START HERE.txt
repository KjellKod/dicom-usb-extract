DICOM USB Extract

For Apple silicon Mac users:

This is for Macs with Apple chips, such as M1, M2, M3, M4, and newer.
Intel Macs are not a target for this project.

1. Insert the medical imaging USB drive.
2. Double-click DICOM USB Extract.app.
3. Choose the USB drive, the IMAGES folder, or a copied study folder.
4. Choose where to save the extracted images, such as Pictures.

The app will open the extracted folder when it finishes.

It does not run AutoRun.exe or any other program from the USB drive.

First launch note: this app is not Apple-notarized. If macOS blocks it the first
time, right-click Open is expected.

If macOS says the app is from an unidentified developer, damaged, or cannot be opened:

1. Right-click DICOM USB Extract.app.
2. Choose Open.
3. Choose Open again.

After that, normal double-click launch should work.
